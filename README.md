# FinTracker

This repo contains the **FinTracker mobile app** built with **React Native + Expo**.

## Run the mobile app

Prereqs:
- Node.js installed (recommended: **Node 20.19+**)
- For real-device testing: install **Expo Go** on your phone

Commands:

```bash
cd mobile
npm install
npm run start
```

Then:
- Press `a` to open on Android (emulator or USB device), or run:
  - `npm run android`
- For iOS builds you’ll need macOS/Xcode; on Windows you can still use Expo Go for iOS testing.

- `mobile/`: Expo (React Native) app
